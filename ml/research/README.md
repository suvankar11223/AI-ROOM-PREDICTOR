# Model research and validation materials

These are the supplementary validation, calibration, subgroup, feature-importance, monitoring,
training and test utilities retained from the earlier model release. They are preserved as
research artifacts; their presence does not mean every proposed validation or monitoring gate
has been completed or connected to the live application.

See `../model_metadata.json` and `validation_status.json` for the current status and limitations.
The runtime API loads only the two versioned model bundles in `../artifacts/`.
